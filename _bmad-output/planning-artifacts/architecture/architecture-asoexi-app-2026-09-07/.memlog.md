- (decision) AD-1: Astro Islands Architecture. Binds: all frontend and backend code. Prevents: monolithic client hydration and slow mobile LCP. Rule: Catalog, brand, and informational pages are 100% prerendered SSG HTML; interactive components (Search, Cart Drawer, Contact Modal) are isolated Preact islands loaded on client demand.
- (decision) AD-2: Git-Based Content Collections. Binds: catalog, brands, categories data. Prevents: database maintenance, outages, and content drift. Rule: Products and brands reside in src/content/ validated by Zod schemas in src/content.config.ts; product images reside in src/assets/ to leverage Astro automatic WebP/AVIF image optimization.
- (decision) AD-3: Cross-Island State via Nano Stores. Binds: quotation cart state. Prevents: framework state fragmentation and hydration errors. Rule: RFQ cart state is managed in src/stores/cart.ts using @nanostores/persistent, synchronized automatically with localStorage without server-side rendering execution.
- (decision) AD-4: Bifurcated RFQ Channelization. Binds: quote submission flows. Prevents: manual data reentry and lost customer inquiries. Rule: Client-side cart generates structured WhatsApp messages containing customer fiscal data, delivery address, and SKU line-items; formal RFQ with credit requests submit via POST to /api/quote.
- (decision) AD-5: Edge Deployment on Cloudflare Pages. Binds: hosting, runtime environments. Prevents: high infrastructure costs and slow geographical routing. Rule: Application deploys to Cloudflare Pages using @astrojs/cloudflare adapter; secrets (RESEND_API_KEY) are injected as Cloudflare environment variables and never exposed to client bundles.
- (decision) AD-6: Unified SEO & JSON-LD Structured Data. Binds: SEO metadata, search engine discovery. Prevents: missing or malformed metadata across catalog pages. Rule: All pages consume a centralized SEOHead layout injecting canonical links, OpenGraph tags, and Schema.org JSON-LD (Organization, LocalBusiness Bogotá/Sabana, Product, BreadcrumbList).
- (decision) AD-7: Multipart Upload & Attachment Sanitization. Binds: /api/quote endpoint. Prevents: memory exhaustion in Edge isolate and malicious file execution. Rule: RFQ uploads are limited to 5MB, restricted to PDF, JPEG, PNG MIME types, processed as in-memory buffers directly forwarded to Resend API without temporary filesystem writes.
